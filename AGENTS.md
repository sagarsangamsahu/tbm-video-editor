# Agent instructions

This repository holds two agent skills:
- `tbm-short-form-video/`: one short video (up to 3 minutes) into finished reels and variations.
- `tbm-video-editing/`: long videos (podcasts, webinars, raw recordings) into many reels, ads, titles and descriptions.

Pick the skill that fits the video, read its `SKILL.md` and follow it.
Install by copying both folders into the agent's skills folder (Claude Code: `~/.claude/skills/`; Codex: `~/.codex/skills/`).
Never commit videos, renders, API keys or personal files.
