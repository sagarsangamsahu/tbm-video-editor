# TBM Video Editor

Free AI video editing skills from **Sagar Sangam Sahu** (Tribe Building Mastermind), for Claude Code.
Drop in a video, type what you want, and get finished reels, YouTube Shorts, TikToks, ads and clips. No editing skills, no Terminal, no paid tools.

## Two skills in one repo

| Skill | Use it for |
|---|---|
| [`tbm-short-form-video`](tbm-short-form-video/SKILL.md) | **A short video (up to 3 minutes) into finished reels.** Organic reel, paid ad, testimonial, promo, tips list, story or quote clip. 3 hook versions, full cut and 15-30 s teaser, 3 caption looks, 9:16 / 4:5 / 1:1, optional sound effects. Start here. |
| [`tbm-video-editing`](tbm-video-editing/SKILL.md) | **A long video into many reels.** Podcasts, interviews, webinars, lives and long raw recordings: finds the best moments, cuts them into vertical reels with captions and hooks, makes paid-ad versions with an end card, and writes titles and descriptions. |

**Any language:** English, Hindi, Hinglish, Tamil, Telugu, Bengali, Odia, Gujarati, Marathi and more, with captions in the language and script you choose.

## Where it works
- **Claude desktop app, Code tab** (Windows and Mac). Editing runs on your own computer.
- **Claude Code in the browser** (claude.ai/code). Editing runs on Claude's computer, good if your laptop is old or low on RAM. You upload the video on a page it opens and download the finished reel.

## Install

**Desktop app (Windows or Mac):**
1. Make a folder (for example `My Reels` on your Desktop) and put your video in it.
2. Open the Claude desktop app, go to the **Code** tab and choose that folder.
3. Send this message:
   `Install the skills from https://github.com/sagarsangamsahu/tbm-video-editor into my Claude skills folder.`
4. Quit and reopen Claude, open the same folder, and type `START`.

**Browser (claude.ai/code):** start a session, attach [`tbm-short-form-video/SKILL.md`](tbm-short-form-video/SKILL.md) (or connect this repository) and type `START`.

The first run sets up the free tools it needs (about 5-10 minutes, once).

## Tips
- One video per chat. Ask for all your changes in one message: it saves your Claude usage.
- Record in good light, phone at eye level, and say your first strong line in the first 3 seconds.
- Claude cannot hear: watch the finished reel once with sound on.
